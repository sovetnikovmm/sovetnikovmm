# Max Sovetnikov

I am a hardware engineer focused on circuit design, PCB development, and microcontroller-based systems. My work spans circuit simulation, schematic capture, PCB layout, and prototype assembly and debugging. I am interested in embedded systems roles and graduate study in embedded systems.

B.Sc. with honors in Electronic Design and Technology, Bauman Moscow State Technical University, 2026.

## Skills

| Area | Skills and tools |
|---|---|
| Circuit design | Analog and digital circuits, STM32-based devices |
| PCB design | Altium Designer, KiCad; single-layer and two-layer PCBs; SMD and through-hole components |
| Manufacturing | Gerber generation, PCB ordering |
| Circuit simulation | NI Multisim, Proteus |
| Mechanical design | KOMPAS-3D; device enclosures, part and assembly drawings |
| Engineering documentation | GOST-compliant block (E1), functional (E2), and circuit (E3) diagrams; PCB drawings; parts lists; specifications; PCB and device assembly drawings |
| Assembly | Soldering iron, hot-air station, soldering hot plate |
| Testing and debugging | Multimeter, oscilloscope, bench power supplies; device bring-up and debugging |
| Embedded systems | Firmware flashing; basic STM32 programming in C using STM32CubeIDE |
